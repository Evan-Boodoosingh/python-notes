# Intro to Python Notes

My notes and practice for Intro to Python. AI suggestions are turned off in this
workspace on purpose: everything here gets written by hand.

## Layout

```
python-notes/
  README.md            this file
  recall-log.md        tracks what I can write cold, and on which days
  templates/           copy these when starting a new unit
    notes-template.md
    practice-template.ipynb
  unit-01/             one folder per unit or week
    notes.md           concepts in my own words
    practice.ipynb     notes + runnable code side by side
    scratch.py         plain script for testing ideas in the terminal
```

## Starting a new unit

1. Copy `unit-01` or the files in `templates/` into a new folder, like `unit-02`.
2. Rename the headings to match the course unit.
3. Fill in notes as you go, test every concept in the notebook.

## Running code

Notebook: open `practice.ipynb`, pick the Python kernel (top right), then
Shift+Enter runs a cell.

Script: open `scratch.py` and click the play button (top right), or in the
terminal run `python3 unit-01/scratch.py`.

## The rule

A concept only counts as learned when I can write it from memory, with no
notes, on at least three different days. Log it in `recall-log.md`.
